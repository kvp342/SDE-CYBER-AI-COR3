## Android: AnkiDroid (free)

1.  Download the .csv files from the repository on your phone (open the file on GitHub, then Raw, then save).
2.  In AnkiDroid: menu → Import → choose the file. Check that the type is Basic, the separator is semicolon, and Field 1 is Front, Field 2 is Back.
3.  Repeat for each file. Each lands in its own deck under "Placement".

## iPhone: AnkiMobile (paid) or AnkiWeb (free in the browser)

1.  Easiest: import on a computer with Anki desktop (free), then sync to a free AnkiWeb account, then sync on the phone.
2.  AnkiMobile can also import the file from the Files app via the share sheet.

## Computer: Anki desktop (free)

1.  File → Import → pick a .csv. The first lines of each file tell Anki the separator, note type, deck and tags, so the defaults should already be right.
2.  If your Anki is older and shows lines starting with \# as cards, delete those cards; they are only settings.

## Daily routine

1.  New cards per day: 15 (Settings → New cards/day). Reviews come back on their own.
2.  Answer honestly: Again if you could not say it out loud; Good if you could.
3.  When a card keeps failing, open the matching Knowledge Base page and rewrite the card in your own words.
4.  Add your own cards for every DSA problem you got wrong: front = problem name and signal, back = the key idea in one line.

Anki is free on desktop, Android and the web. The decks are plain text, so you can also open them in any spreadsheet app.
