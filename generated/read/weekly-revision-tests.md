## WEEK 1. Answers

Score 1 point each. Under 60%: redo the week's problems this week and add every miss to Anki.

**1. Two Sum**: **Hashing**. Brute force checks every pair: O(n²). Instead, walk once and remember each value's index in a hash map. For each x, the partner you need is target − x; if it's already in the map, you're done. Check the map before inserting x, so an element is never paired with itself. *Complexity: O(n) time, O(n) space.* Full solution: Knowledge Base.

**2. Product of Array Except Self**: **Prefix sum**. answer\[i\] = (product of everything left of i) × (product of everything right of i). Fill left products in one pass, then multiply by a running right product in a second pass. *Complexity: O(n) time, O(1) extra space (the output doesn't count).* Full solution: Knowledge Base.

**3. Next Permutation**: **Two pointers**. From the right, find the first i with a\[i\] \< a\[i+1\] (the pivot). If none, reverse the whole array. Otherwise swap a\[i\] with the rightmost element greater than it, then reverse the suffix after i (it was descending). *Complexity: O(n) time, O(1) space.* Full solution: Worked Solutions II.

**4. A** (Shortest Job First). Short jobs always go first, so a long job can wait forever; aging fixes it.

**5. A** (Preemption). The condition is no preemption; allowing preemption breaks deadlock.

**6. D** (Avoidance). It grants a request only if the system stays in a safe state.

**7. A** (Processes spend more time paging than executing). Too few frames per process causes constant page faults.

**8. B** (DynamoDB global tables). Global tables replicate across Regions with multi-active writes.

**9.** NTLM is a challenge-response protocol without mutual authentication and is open to relay and pass-the-hash; Kerberos uses tickets from a trusted KDC, supports mutual authentication and is the default in Active Directory.

**1. Maximum Subarray (Kadane)**: **Kadane**. At each index, the best subarray ending here either extends the best one ending at i−1 or starts fresh at i: cur = max(a\[i\], cur + a\[i\]). The answer is the best cur seen. *Complexity: O(n) time, O(1) space.* Full solution: Knowledge Base.

**2. Longest Consecutive Sequence**: **Hashing**. Put all numbers in a hash set. Only start counting from x when x − 1 is not in the set (x is the start of a run), then walk x+1, x+2… Each number is visited at most twice, so the total is O(n). *Complexity: O(n) average time, O(n) space.* Full solution: Knowledge Base.

**3. Majority Element (Boyer–Moore)**: **Hashing**. Pair each majority element with a different element and cancel; the majority survives. Keep a candidate and a count: on count 0 take the current element, add 1 if equal, else subtract 1. *Complexity: O(n) time, O(1) space.* Full solution: Worked Solutions II.

**4. B** (2NF). 2NF: every non-key attribute depends on the whole key.

**5. C** (3NF). 3NF: non-key attributes depend only on keys.

**6. D** (Every determinant is a candidate key). Stricter than 3NF.

**7. A** (Isolation). Concurrent transactions do not see each other's partial work.

**8. C** (SSE-KMS with a customer managed key). KMS key use appears in CloudTrail and customer managed keys have company-controlled policies and rotation.

**9.** -sS sends SYN and resets on SYN-ACK (never completes the handshake, needs raw-socket privileges); -sT uses the OS connect() call and completes it (no privileges needed, more likely to be logged).
